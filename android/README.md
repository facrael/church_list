# Религиозный Маркетплейс - Android App

Android приложение для поиска храмов, записи на услуги и духовного развития.

## Технологии

- **Kotlin** - основной язык программирования
- **Jetpack Compose** - современный UI toolkit
- **Material 3** - дизайн-система
- **Hilt** - Dependency Injection
- **Navigation Compose** - навигация между экранами
- **Retrofit** - сетевые запросы
- **Coil** - загрузка изображений
- **2GIS SDK** - карты (TODO: интеграция в разработке, API ключ: a6a0e70d-a34e-4f94-83ff-425d07d36042)
- **Room** - локальная база данных
- **DataStore** - хранение настроек

## Экраны

1. **Главная** - приветствие, ближайшие храмы, популярные услуги, события
2. **Карта** - поиск храмов на карте с фильтрами по религии
3. **Детали храма** - информация, услуги, расписание, отзывы
4. **Бронирование** - выбор даты и времени
5. **Заказы** - активные и завершённые записи
6. **Молитвы** - тексты молитв разных религий
7. **Профиль** - настройки и статистика

## Запуск

### Требования
- Android Studio Hedgehog (2023.1.1) или новее
- JDK 17
- Android SDK 34
- Kotlin 1.9.20

### Шаги

1. Откройте папку `android` в Android Studio
2. Дождитесь синхронизации Gradle
3. API ключ 2GIS уже добавлен в `AndroidManifest.xml`
4. Запустите на эмуляторе или устройстве

**Примечание:** Используется тот же API ключ 2GIS, что и в веб-прототипе:
`a6a0e70d-a34e-4f94-83ff-425d07d36042`

### Сборка APK

```bash
./gradlew assembleDebug
```

APK будет в `app/build/outputs/apk/debug/`

## API

Приложение готово к интеграции с бэкендом. Текущая версия использует локальные данные.

Для подключения к API:
1. Создайте интерфейсы в `data/api/`
2. Настройте Retrofit в `di/NetworkModule.kt`
3. Обновите репозитории для использования API
